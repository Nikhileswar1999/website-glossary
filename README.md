# Global Wealth & Risk Tools Hub

Lightweight, responsive fintech website with:
- Interactive calculators (wealth, loans, risk, currency)
- Country-based glossary tabs (USA, UK, Singapore, India)
- Learning mode (ELI12 + advanced)
- Engagement modules (save/share results, score, tips, trending terms)
- Ad-friendly layout placeholders

## Run locally

Open `index.html` directly in a browser.
