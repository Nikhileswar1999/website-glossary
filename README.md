# website-glossary

Phase 1 implementation: a fast, client-side **JSON Formatter + JSON Validator** with a dual-pane editor UI.

## Features

- JSON format/beautify with 2, 3, or 4 space indentation
- JSON validation with line/column-aware error output
- Actionable suggestions for common syntax issues
- Optional real-time validation/formatting
- Optional auto-fix for simple issues (single quotes and trailing commas)
- Upload and drag-drop JSON files
- Copy output and download formatted JSON
- Autosave input and theme preference in local storage
- Light and dark mode support

## Run locally

Open `index.html` directly in your browser.
