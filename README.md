# JSON Formatter & Validator

A lightweight, client-side JSON tool with a dual-pane editor for formatting and validation.

## Features

- JSON beautify with indentation choices (2, 3, or 4 spaces)
- JSON validation with actionable error messaging (line + column)
- Optional real-time formatting
- Optional auto-fix for simple issues (single quotes, trailing commas)
- Upload JSON file or drag-and-drop support
- Copy output and download formatted JSON
- Scroll sync, line numbers, syntax highlighting
- Auto-save input and theme preference via localStorage
- Light/Dark mode

## Run

Open `index.html` in a browser.
